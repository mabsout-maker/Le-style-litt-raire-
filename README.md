# Le Style Littéraire — version finale

## Contenu
- `index.html` : structure du site
- `style.css` : design, responsive et animations
- `script.js` : recherche, filtres et interactions
- `images/` : logo transparent + 5 images de vidéos

## Vidéos intégrées
1. Histoire de la littérature du 20ème siècle
2. L'Assommoir — Émile Zola
3. Le Comte de Monte-Cristo — Alexandre Dumas
4. L'Étranger — Albert Camus
5. Madame Bovary — Gustave Flaubert

Les vidéos « Le Bateau ivre » et « L'Albatros » ont volontairement été retirées de cette version.

## Mise en ligne sur GitHub Pages
1. Ouvrir le dépôt GitHub.
2. Remplacer l'ancien `index.html` par celui-ci.
3. Ajouter `style.css`, `script.js` et le dossier `images`.
4. Dans GitHub : Settings → Pages → Deploy from branch → `principal` (ou `main`) → `/ (root)`.
5. Attendre la publication de GitHub Pages.

Pour ajouter une nouvelle vidéo plus tard, dupliquer une carte dans `index.html`, remplacer son image, son titre, sa description, sa catégorie et son lien YouTube.
